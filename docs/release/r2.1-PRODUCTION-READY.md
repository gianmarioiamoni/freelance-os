## Deployment Instructions

### 1. Configure Production Environment

Add via hosting platform (Vercel/AWS/other):

```bash
AI_PRODUCTION_ENABLED=true
AI_PRODUCTION_BASE_URL=https://api.anthropic.com/v1
AI_PRODUCTION_API_KEY=<your-anthropic-api-key>
AI_PRODUCTION_MODEL=claude-haiku-4-5-20251001
```

**Security checklist:**
- [ ] Obtain Anthropic API key from https://console.anthropic.com
- [ ] Configure all 4 environment variables
- [ ] Verify server-only scope (no `NEXT_PUBLIC_` prefix)
- [ ] Store API key in secure secrets manager
- [ ] Never commit API key to repository

### 2. Deploy

```bash
git checkout 0b1f58b
git push origin main
```

Or deploy via hosting platform dashboard.

### 3. Post-Deployment Validation

**Quick check (5 minutes):**

1. Navigate to Reports → locate "Ask about your analytics" box
2. Submit: "Quanto ho maturato a gennaio 2026?"
3. Verify: Italian response with revenue figure + citations
4. Navigate to Reports again → submit another question
5. Check logs: no errors, no credential leakage
6. Verify Dashboard has NO AI ask-box (Phase 2 change)

**Expected outcome:**
- AI responds with grounded Italian prose
- Citations reference contracts/figures from DTOs
- No "AI unavailable" message
- No errors in production logs
- Dashboard shows analytics cards only (no AI entry point)

**If validation fails:** See § 4 (Rollback)

### 4. Rollback (if needed)

Immediate rollback without code changes:

```bash
AI_PRODUCTION_ENABLED=false
```

Effect:
- AI ask-box shows "AI unavailable" message
- No provider calls, no costs
- No crash, no data loss
- Can re-enable by setting `AI_PRODUCTION_ENABLED=true`
