## STEP 1: Configure Production Environment

### 1.1 Access Hosting Platform

Log in to your production hosting platform dashboard.

### 1.2 Add Environment Variables

Navigate to: Settings → Environment Variables (or equivalent)

Add these **4 required variables**:

| Variable | Value | Notes |
|---|---|---|
| `AI_PRODUCTION_ENABLED` | `true` | Enables production AI |
| `AI_PRODUCTION_BASE_URL` | `https://api.anthropic.com/v1` | Anthropic API endpoint |
| `AI_PRODUCTION_API_KEY` | `<your-anthropic-api-key>` | **SECRET** - Never commit |
| `AI_PRODUCTION_MODEL` | `claude-haiku-4-5-20251001` | Certified model |

### 1.3 Verify Security

- [ ] All variables are **server-only** (no `NEXT_PUBLIC_` prefix)
- [ ] API key is stored in **secure secrets manager**
- [ ] API key is **never visible in logs**
- [ ] API key is **never committed to git**

### 1.4 Save Configuration

Save/apply environment variables in your hosting platform.

**⚠️ DO NOT PROCEED until all 4 variables are configured correctly.**

## STEP 7: Monitoring (Post-Success)

### 7.1 First 24 Hours

Monitor these metrics:

- **Request volume:** Track AI requests/hour
- **Success rate:** Should be >90% for valid questions
- **Error rate:** Should be <5%
- **Refusal rate:** Variable (out-of-scope questions expected)
- **Latency p50/p95:** Expected ~1100ms / ~2000ms
- **Cost:** Expected ~$0.005 per request

### 7.2 Alert Conditions

Set up alerts for:

- Error rate >10%
- p95 latency >8000ms (timeout)
- Credential leakage detected
- Cross-workspace data in responses
- Unexpected costs

### 7.3 User Feedback

Monitor for:

- Incorrect financial figures (would indicate grounding failure)
- Invented data (should never happen)
- Cross-workspace data (would indicate tenant isolation failure)
- Unexpected refusals (may indicate contract issue)

## Support

### Troubleshooting

**"AI unavailable" in production:**
- Verify all 4 environment variables are set
- Verify API key is valid
- Check production logs for configuration errors

**HTTP 401/403 errors:**
- Verify Anthropic API key in https://console.anthropic.com
- Regenerate key if necessary
- Update `AI_PRODUCTION_API_KEY` in production

**Timeout errors:**
- Check Anthropic API status
- Monitor p95 latency
- Review recent usage spike

**Unexpected responses:**
- Check production logs for request/response
- Verify no safety regression (no writes, no invented data)
- Document in residual analysis
