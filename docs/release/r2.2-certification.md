## 1. Scope

R2.2 delivers workspace-level revenue visibility, Monthly Timesheet reporting, and export surfaces without redefining Invoice/Payment creation, Accrued/Expected formulas, FX, or fiscal invoice PDF generation.

**In scope (implemented):**
1. Revenue Visibility — `RevenueOverview` (Accrued, Expected, Forecast when present, Invoiced, Paid, Outstanding)
2. Workspace Invoice Access — `/invoices` list/filters + navigation
3. AI Assistant Separation — `/assistant`; Reports no longer embeds AI ask-box
4. **Monthly Timesheet Report** — `/reports` with month/client filtering, daily expandable detail, amount to invoice
5. **Shared Export Dataset** — unified timesheet data structure for CSV/Excel/PDF
6. Excel Export — server XLSX for Revenue, Hours by Client, Contract Report, **Monthly Timesheet** + Reports UI
7. PDF Export — server PDF for the same datasets + Reports UI; **PDF production font fix** (`cc532d46`)

**Out of scope (unchanged):** profitability/PIVA costs, FX/mixed-currency totals, bulk invoice ops, fiscal invoice documents, new AI capabilities, unrelated redesigns.

## 3. Product / architecture summary (as shipped)

- **Revenue:** `ReportingService.getRevenueOverview` reuses AnalyticsService Accrued/Expected/Forecast and `WorkspaceInvoiceService` Invoiced/Paid/Outstanding. Currency separation preserved; no FX; no mixed totals.
- **Invoices:** workspace list/filters on `/invoices`; creation/payment remain Contract-scoped.
- **AI:** ask surface on `/assistant`; Reports has entry link only; tool registry/security unchanged.
- **Monthly Timesheet:** `ReportingService.getMonthlyTimesheet(context, period, clientId)` serves as single source of truth for UI (`MonthlyTimesheetTable.tsx`) and exports. Reuses `AnalyticsService.getDailyAnalytics` + `calculateAccruedRevenue`. Month/client filtering required. Expandable daily detail with entry-level breakdown. Amount to invoice derived from existing billing logic (no formula changes).
- **Export Dataset:** Shared `MonthlyTimesheetExportDataset` structure used by CSV, Excel, PDF serializers (`monthly-timesheet-export.ts`, `monthly-timesheet-csv.ts`, `monthly-timesheet-xlsx.ts`, `monthly-timesheet-pdf.ts`). Eliminates serializer duplication.
- **Excel:** `serializeReportXlsx` + `GET /reports/export/excel` (`xlsx@0.18.5`, server-only).
- **PDF:** `serializeReportPdf` + `GET /reports/export/pdf` (`pdfmake@0.3.11`, server-only, Roboto via embedded VFS — no node_modules TTF filesystem paths; production fix `cc532d46`).
- **Authz:** export routes use authenticated workspace context; client `workspaceId` is not authoritative.
