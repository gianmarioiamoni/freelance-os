## Deployment Overview

### Step 1: Configure Environment (5 min)

Add 4 environment variables in your hosting platform:

```bash
AI_PRODUCTION_ENABLED=true
AI_PRODUCTION_BASE_URL=https://api.anthropic.com/v1
AI_PRODUCTION_API_KEY=<your-anthropic-api-key>
AI_PRODUCTION_MODEL=claude-haiku-4-5-20251001
```

**Security:** Never commit the API key. Use your platform's secrets manager.

### Step 2: Deploy (5 min)

```bash
git checkout d17b8ac
git push origin main
```

Or deploy via your hosting platform dashboard.

### Step 3: Validate (10 min)

**Dashboard test:**
